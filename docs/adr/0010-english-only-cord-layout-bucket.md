# ADR-010: English-only v1; CORD is an out-of-language layout bucket

Status: **locked** (DQ-04 = A; seeded from `PROJECT(1).md` §14; governs ticket 03a loaders and all published accuracy).

UI/product language support is English-only. Parser label dictionaries include English/Indian-English for the product; Indonesian labels exist only for CORD benchmarking/layout stress. Do not mix CORD scores into headline English accuracy. SROIE is scored only for the fields actually annotated and supported by this parser (grand-total-only).
